# OGENIUS — Telegram-репетитор по ОГЭ по русскому языку

Telegram-бот на Python + aiogram 3. Включает меню обучения, памятки, разбор направлений заданий, тренировочный квиз с объяснениями, статистику и подключаемого ИИ-репетитора.

## Возможности
- Обучающие конспекты: НЕ/НИ, Н/НН, пунктуация, изложение и сочинение.
- Раздел с навигацией по заданиям ОГЭ.
- Тренировка с ответами и объяснением ошибок.
- Личная статистика (SQLite).
- ИИ-репетитор через OpenAI-совместимый Chat Completions API.
- HTTP `/health` для проверки доступности Render.

## Запуск локально
1. Установи Python 3.12+.
2. `pip install -r requirements.txt`
3. Создай переменную окружения `BOT_TOKEN` с токеном от @BotFather.
4. Необязательно: `OPENAI_API_KEY` и при необходимости `AI_BASE_URL`, `AI_MODEL`.
5. `python main.py`

## Деплой на Render
Создай Web Service из этого репозитория. Build Command: `pip install -r requirements.txt`. Start Command: `python main.py`. Добавь `BOT_TOKEN` в Environment. Для ИИ добавь `OPENAI_API_KEY` и при необходимости `AI_MODEL`.

`/health` и `/` возвращают статус сервиса. Render Free может засыпать после периода без входящих HTTP-запросов; health endpoint сам по себе не гарантирует постоянную работу. Внешний мониторинг может периодически проверять `/health`, но доступность бесплатного тарифа не гарантируется.

## Важно про актуальность экзамена
Номер и содержание заданий, критерии и шкалы нужно сверять с документами нужного года на официальном сайте ФИПИ: https://fipi.ru/oge/demoversii-specifikacii-kodifikatory . Материалы в первой версии — учебный стартовый набор, а не полный официальный банк ФИПИ. Не публикуйте закрытые варианты и не выдавайте тренировочные вопросы за задания ФИПИ.

## Переменные окружения
- `BOT_TOKEN` — обязательно.
- `OPENAI_API_KEY` — необязательно, включает ИИ-репетитора.
- `AI_BASE_URL` — необязательно, по умолчанию `https://api.openai.com/v1`.
- `AI_MODEL` — необязательно, по умолчанию `gpt-4o-mini`.
- `PORT` — задаёт Render автоматически.
- `DB_PATH` — необязательно, путь к SQLite-файлу.
